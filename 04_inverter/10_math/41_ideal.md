# Three-phase inverter: ideal design

> [!NOTE]
> Operating point, modulation, DC link and semiconductor stresses of the three-phase voltage-source inverter box (six-switch bridge), with ideal components. The DC link comes from the rectifier box ($\approx 280\,\mathrm{V}$), the boost box ($300\,\mathrm{V}$) or the lab DC supply ($110\,\mathrm{V}$); the six gate signals come from the gating block.

## 1. Design premises

|           Parameter            |                                       Value                                       |                 Note                 |
| :----------------------------: | :-------------------------------------------------------------------------------: | :----------------------------------: |
|   DC-link voltage ($V_{dc}$)   |                 $280\,\mathrm{V}$ nominal, $60$–$320\,\mathrm{V}$                 |                                      |
|   Rated output power ($P_o$)   |                                 $300\,\mathrm{W}$                                 |    Lamp bank (Y or Δ) or reactor     |
|      Rated phase current       |                               $2\,\mathrm{A_{rms}}$                               |    $I_m = 2.83\,\mathrm{A}$ peak     |
|    Output frequency ($f_1$)    |                $0.1$–$400\,\mathrm{Hz}$, $60\,\mathrm{Hz}$ default                |                                      |
| Switching frequency ($f_{sw}$) |            $10\,\mathrm{kHz}$ nominal (IGBT), up to $20\,\mathrm{kHz}$            |                                      |
|           Modulation           | Sinusoidal PWM ($m_a \leq 1$), six-step ($180^\circ$) and $120^\circ$ square wave |     Selected on the gating block     |
|           Dead time            |                           $1.5\,\mathrm{\mu s}$ (IGBT)                            |    Generated by the gating block     |
|         Output filter          |                       None on board (optional external LC)                        | Lamps and reactor accept PWM voltage |

---
## 2. Topology

Three half-bridge legs $(Q_1, Q_4)$, $(Q_3, Q_6)$, $(Q_5, Q_2)$ across the DC link, outputs $A, B, C$ at the midpoints. Each switch is an IGBT with anti-parallel diode (co-pack). The three lower emitters share the DC− rail, so one isolated supply feeds the three low-side drivers and the protection circuit; each upper switch has its own isolated supply (four 15 V DC/DC modules in total).

---
## 3. Output voltage

**Sinusoidal PWM, linear range ($m_a \leq 1$):**

$$
\hat V_{AN,1} = m_a\frac{V_{dc}}{2}
\qquad
V_{LL,1,rms} = \frac{\sqrt{3}}{2\sqrt{2}}\, m_a V_{dc} = 0.612\, m_a V_{dc}
$$

| $V_{dc}$ | $m_a = 0.8$ | $m_a = 1.0$ | Six-step ($0.78\,V_{dc}$) |
| -------- | ----------- | ----------- | ------------------------- |
| $110\,\mathrm{V}$ | $54\,\mathrm{V}$ | $67\,\mathrm{V}$ | $86\,\mathrm{V}$ |
| $280\,\mathrm{V}$ | $137\,\mathrm{V}$ | $171\,\mathrm{V}$ | $218\,\mathrm{V}$ |
| $320\,\mathrm{V}$ | $157\,\mathrm{V}$ | $196\,\mathrm{V}$ | $250\,\mathrm{V}$ |

A $208\,\mathrm{V_{LL}}$ fundamental is not reachable with $280\,\mathrm{V}$ on the DC link in the linear range: it needs six-step operation at $\geq 267\,\mathrm{V}$ or a $340\,\mathrm{V}$ link (12-pulse rectifier in series, or the boost at full output). The course experiments therefore use a $110\,\mathrm{V}$ lamp bank in Y ($V_{LL} = 190\,\mathrm{V}$ needed, $m_a = 1$ at $320\,\mathrm{V}$) or in Δ with reduced voltage.

**Six-step ($180^\circ$ conduction):** $V_{LL,1,rms} = \dfrac{\sqrt{6}}{\pi} V_{dc} = 0.78\,V_{dc}$, line-to-line harmonics of order $6k \pm 1$ with amplitude $1/n$, THD $31\,\%$.

**PWM harmonics:** with $m_f = f_{sw}/f_1 = 167$ (asynchronous) the first significant harmonics sit around $f_{sw}$ and $2 f_{sw} \pm f_1$; the line-to-line THD in the linear range is $\approx 50$–$80\,\%$ at $m_a = 0.8$ (mostly above $10\,\mathrm{kHz}$, filtered by any inductance in the load).

---
## 4. Currents and DC link

Rated phase current $I_{rms} = 2\,\mathrm{A}$ ($I_m = 2.83\,\mathrm{A}$), unity power factor with lamps ($\cos\varphi \approx 0.8$ lagging with the reactor).

| Quantity | Expression | Value ($m_a = 0.8$, $\cos\varphi = 1$) |
| -------- | ---------- | -------------------------------------- |
| Switch average current | $I_m\left(\dfrac{1}{2\pi} + \dfrac{m_a\cos\varphi}{8}\right)$ | $0.73\,\mathrm{A}$ |
| Switch RMS current | $I_m\sqrt{\dfrac{1}{8} + \dfrac{m_a\cos\varphi}{3\pi}}$ | $1.27\,\mathrm{A}$ |
| Diode average current | $I_m\left(\dfrac{1}{2\pi} - \dfrac{m_a\cos\varphi}{8}\right)$ | $0.17\,\mathrm{A}$ |
| Diode RMS current | $I_m\sqrt{\dfrac{1}{8} - \dfrac{m_a\cos\varphi}{3\pi}}$ | $0.60\,\mathrm{A}$ |
| DC-link average current | $P_o / V_{dc}$ | $1.07\,\mathrm{A}$ |
| DC-link capacitor RMS current | $I_{rms}\sqrt{2\sqrt{3}\,m_a\left(\dfrac{1}{4\pi} + \dfrac{\cos^2\varphi}{\pi}\left(1 - \dfrac{9\sqrt{3}\,m_a}{16\pi}\right)\right)}$ | $\approx 0.9\,\mathrm{A}$ |

**DC-link capacitor.** The capacitor must carry $0.9\,\mathrm{A_{rms}}$ at $f_{sw}$ and keep the link stiff:

$$
\Delta V_{dc} \approx \frac{I_{C,rms}}{2\pi f_{sw} C_{dc}}
\quad\Rightarrow\quad
C_{dc} = 94\,\mathrm{\mu F}:\ \Delta V_{dc} \approx 0.15\,\mathrm{V}
$$

**Selected: $2 \times 47\,\mathrm{\mu F}$, $450\,\mathrm{V}$ electrolytic + $4.7\,\mathrm{\mu F}$ film** (same parts as the DC/DC boxes). Each electrolytic carries about $0.35\,\mathrm{A}$ and the film capacitor, placed at the bridge, takes the switching edges. Stored energy $\tfrac{1}{2} C V^2 = 3.7\,\mathrm{J}$ at $280\,\mathrm{V}$ (bleeder resistor required, see section 6).

## 6. Protection and measurement

- **Dead time.** $1.5\,\mathrm{\mu s}$, set in the gating block, covers the HCPL-3120 propagation delay skew ($\leq 0.5\,\mathrm{\mu s}$) plus the IGBT turn-off ($\leq 0.6\,\mathrm{\mu s}$ with current tail). Shoot-through protection relies on it: there is no hardware interlock on the board (see the gating block design).
- **Over-current.** $0.1\,\Omega$ shunt in the DC− rail, comparator trip default $4\,\mathrm{A}$ (peak DC-link current), pulls `FAULT` low.
- **Over-voltage.** DC-link divider, trip at $400\,\mathrm{V}$ (regenerative load, e.g. reactor current returning energy when the modulation stops).
- **Bleeder.** $2 \times 100\,\mathrm{k\Omega}$ 0.5 W across the DC link discharge $94\,\mathrm{\mu F}$ with $\tau = 19\,\mathrm{s}$ ($< 50\,\mathrm{V}$ after $35\,\mathrm{s}$); the pilot LED in the same chain shows "DC link charged".
- **Inrush.** $10\,\Omega$ NTC in the DC+ input.
- **Test points.** `V_DC`, `A`, `B`, `C`, `I_DC` ($0.1\,\mathrm{V/A}$), `GND_P`.
- **Fuse.** 5×20 mm, $4\,\mathrm{A}$ T on the DC input.
